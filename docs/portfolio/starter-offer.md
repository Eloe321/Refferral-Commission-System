# Starter client offer

**Referral and commission workflow audit**

I map how a business attributes referrals, decides eligibility, authorizes claims, handles payouts, and corrects refunds. The fixed-scope deliverable is a workflow diagram, a risk register, a proposed event integration, and an implementation plan with explicit production boundaries.

The audit is an implementation scoping service. It does not include live payment movement, tax advice, KYC, or legal approval.
